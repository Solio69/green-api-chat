# Quickstart: проверка палитры экрана входа

**Задача**: [spec.md](spec.md). Команды выполняются в `D:\Pet-projects\green-api-chat` после реализации. Установки не требуются.

1. Остановить `dev`, если он запущен в этой папке: `test:e2e` использует отдельную production-сборку и собственный сервер.
2. В панели VS Code **NPM Scripts** запустить `typecheck`, `lint`, `format:check`, затем `test:e2e`.
3. После окончания проверок запустить `dev` через **NPM Scripts** и открыть `/`. Сравнить с [референсом А](../../docs/ui-references/login-palette.png) при 1280×720 и 320×568. Проверить исходное состояние, переход Tab, ошибки после пустой отправки, наведение на кнопку/ссылку/глаз и отсутствие горизонтальной прокрутки.
4. Сверить вычисленные CSS-цвета и контраст ссылки/кнопки с FR-001–FR-005. Для обычного текста порог 4.5:1.

Форма пока проверяет только обязательность полей; успешная серверная авторизация относится к другой задаче. Реальные реквизиты для этих проверок не вводить.
