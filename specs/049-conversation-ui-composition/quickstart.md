# Quickstart 049

1. Явно выбрать `SPECIFY_FEATURE_DIRECTORY=specs/049-conversation-ui-composition`; `check-prerequisites.ps1 -Json -RequireSpec/-RequireTasks -ExpectedFeatureDirectory <absolute>` должен вернуть точный `FEATURE_DIR`.
2. До кода подтвердить покрытие: `npm run test -- --run tests/unit/message-domain.test.ts tests/component/notification-notice.test.tsx`; `npm run test:integration -- conversation-selection history-query message-send-controller notification-provider`; `npm run test:query -- conversation-selection message-composer history-window unread-indicators`; `npm run test:e2e -- chat-workspace conversation-selection message-composer history-scroll history-window`. Playwright suites запускать последовательно из-за общего `test-results`.
3. Выполнить согласованный чистый перенос по [inventory](inventory.md), обновить публичные импорты, разделить selection/unread через `ConversationChatListPanel` и props, создать регрессию для history panel hook до переноса. Если понадобится изменение поведения, сначала тест и подтверждённый поведенческий Red, затем код.
4. Проверить отсутствие старых импортов `rg -n '@/components/(ChatHistory|ChatWorkspace|Conversation|Message|Notification)' src tests`; server/client graph; `npm run typecheck`, `npm run lint`, `npm run lint:styles`, `npm run format:check`, `npm run test`, `npm run test:integration`, `npm run test:query`, `npm run test:e2e`.
5. Read-only post-analysis, diff/secret review, commit/push `refactor`, обе GitHub CI jobs и артефакты. Реальных реквизитов и отправки сообщений нет. Новые зависимости, БД и действия пользователя не требуются.
