# Проверка SCSS

Из корня проекта запустить `npm run lint:styles`. Команда проверяет все исходные `src/**/*.scss`, включая SCSS Modules и partial-файлы; она не исправляет файлы. Ошибка содержит путь и позицию. Пустой набор файлов не считается успехом.

Перед сдачей затронутого UI запустить `npm run format:check`, `npm run lint`, `npm run typecheck`, `npm run build` и подходящие существующие UI-тесты. Stylelint проверяет синтаксис и автоматические правила SCSS; выбор семантического токена, миксина и доступность UI остаются предметом ревью.

При проверке конфигурации отдельно подать через stdin корректный SCSS с `@use` и вложенным БЭМ-селектором и некорректный SCSS. Ожидаются exit code 0 и ненулевой exit code с позицией соответственно. Эти примеры не сохраняются как продуктовые файлы.

Зависимости Stylelint уже установлены пользователем. Агент не выполняет установку и не меняет Git index.
