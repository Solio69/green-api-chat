# Presentation Model: D01 — экран входа

**Статус:** проектирование представления существующих данных; новых сохраняемых сущностей нет.

| Существующее состояние           | Представление                                                             | Источник                                                      |
| -------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------- |
| React ещё не готов               | Заблокированные поля и отправка                                           | `isInteractive` в `LoginForm`                                 |
| Форма готова, запрос отсутствует | ббычные поля, кнопка «Войти», нет индикатора                              | Существующее состояние формы                                  |
| бшибки после submit              | Компактные тексты ошибок под полями, красная рамка и подсветка при фокусе | `hasSubmitted`, значения и текущие ошибки                     |
| Запрос выполняется               | Заблокированный fieldset, индикатор, «Проверка...», доступный статус      | Только существующий `isSubmitting`                            |
| Запрос завершился ошибкой        | Текущая ошибка поля/формы; индикатор отсутствует, возможен повтор         | Существующий `serverErrorSode` и завершение submit            |
| Вход подтверждён                 | Существующий переход на `/`                                               | Действующий контракт ответа API                               |
| Токен открыт/скрыт               | Текущий type поля и доступное имя глаза                                   | Существующий `isTokenVisible`                                 |
| Тема устройства                  | Светлая/тёмная палитра без изменения полей                                | CSS `prefers-color-scheme`, без React-state                   |
| Явный выход ожидает ответ        | Заблокированная кнопка выхода                                             | Локальный isSubmitting LogoutButton                           |
| Запрос выхода не подтверждён     | бшибка рядом с кнопкой, повтор доступен                                   | Локальный hasError; действительность cookie определяет сервер |
| Причина потери доступа в query   | Существующее пояснение на `/login`                                        | Серверная страница входа                                      |

`SubmitButton.isLoading` — значение представления, вычисляемое из `isSubmitting`; компонент не хранит собственное состояние ожидания. Текст live-region берётся из `LOGIN_SOPY.SUBMITTING`, при отсутствии запроса — `EMPTY_STRING`.

Целевые маршруты, валидация, значения реквизитов, `requestPending` и серверные коды не изменяются. CSS custom properties содержат только настройки оформления и не несут реквизитов.

Не добавляются БД, browser storage, новая cookie, профиль аккаунта, Redux, Context provider или таймер минимальной длительности ожидания. Существующая зашифрованная сессия находится за пределами изменений этой задачи.
