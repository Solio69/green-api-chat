# Проверка D04

**Сейчас**: адаптивный каркас, уточнения ширины и видимый список автоматически проверены в Chromium. Реализация завершена; полная ручная приёмка NotRun.

1. Войти самостоятельно своими реквизитами. Главная показывает профиль, один выход, поиск и личные чаты из GetChats через Query. Реквизиты агенту не передаются.
2. Проверить подписи существующих чатов. При отсутствии необязательных полей используется username, затем телефон, затем chatId. Чаты пока не открываются; «Написать» остаётся шагом D06.
3. При успешных данных, пустоте и начальной загрузке кнопки обновления нет. При временной ошибке вместо чатов показывается карточка с «Обновить». Нажатие сохраняет карточку на месте, блокирует кнопку и показывает «Обновляем…». Успех возвращает список либо «Пока нет чатов»; повторная ошибка сохраняет карточку. Проверить на фиктивной ошибке автоматическими тестами, не изменяя реальный аккаунт.
4. Проверить обе темы, 320/360/390/768/1280 и широкие 1440/1920/2560 px: доступная прокрутка, отсутствие горизонтального переполнения и сохранение заполненного поиска. Проверить длинные подписи, увеличение текста и короткое окно. Desktop показывает две панели, mobile — левую область.
5. Обновить страницу; выйти и войти в другой аккаунт. Данные старого подключения не должны стать списком нового аккаунта. При отказе сессии сохраняется переход на вход.
6. При свободном .next выполнить npm run test:e2e, npm run lint, npm run lint:styles, npm run typecheck и npm run format:check. E2E включает production build. [Фактические результаты](verification.md), [контракт списка](contracts/list-presentation.md), [итоговый анализ](analysis.md).

Пользователь подтвердил реальный GetChats ранее; это не заменяет ручную приёмку нового UI. Реальные устройства, iPhone/VoiceOver, настоящий browser zoom и полный сценарий нового списка — NotRun. Автотесты используют вымышленные данные; font-size:200% не выдаётся за browser zoom. Не запускать dev и production build в одном .next одновременно; чужие процессы агент не завершает.
