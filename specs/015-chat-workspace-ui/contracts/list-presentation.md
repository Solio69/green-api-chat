## Действие списка

ChatListPanel показывает карточку ошибки вместо ChatList при любой временной ошибке, включая ошибку обновления с сохранёнными данными. В карточке раздельные заголовок, пояснение, декоративный значок и кнопка «Обновить». Начальная загрузка, подтверждённая пустота и успешные данные не имеют действия обновления.

При ручном повторе Panel удерживает только код показанной ошибки до завершения публичного refetch: Query может сбросить error в начале запроса, но карточка не исчезает и старые строки не мелькают. Кэш/данные не копируются. Кнопка показывает «Обновляем…», блокируется; под оба текста и значок зарезервировано одинаковое место. Отдельный role=status объявляет ожидание, alert содержит только ошибку. Успех возвращает список или подтверждённую пустоту, повторная ошибка сохраняет карточку. Успешное фоновое обновление не добавляет видимую строку статуса с изменением высоты. Сессия/изоляция/политика refetch принадлежат 014.
