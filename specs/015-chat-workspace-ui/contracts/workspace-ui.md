# Контракт каркаса D04

**Spec:** [spec.md](../spec.md). Это UI-контракт, новых HTTP API нет.

## Композиция

Успешная серверная главная передаёт в ChatWorkspace именованные slots `account`, `search`, `chatList` типа ReactNode. ChatSidebar располагает их в этом порядке. ConversationEmptyState содержит приглашение выбрать чат/найти получателя; ConversationBackground — только статичный декор. Оболочка без client-state и серверных реквизитов; client-граница остаётся у формы и ChatListPanel.

Один `<main>` остаётся на странице. Каркас не создаёт второй `<main>`; области имеют понятные заголовки/доступные имена. Desktop две колонки 310 px и `minmax(0, 1fr)`, mobile до 680 px включительно — левая область; правая скрыта через CSS также из accessibility tree. При высокой длине/малой высоте контент доступен прокруткой, фиксированная высота не обрезает форму.

Нельзя переключать два экземпляра формы по viewport или давать ей меняющийся key. В D04 нет обработчиков выбора переписки, крестика, composer и mock-сообщений. Узор локальный, `aria-hidden`, не focusable и не принимает pointer events.

## Граница с серверной страницей

Меняется только успешное представление `src/app/page.tsx`. Чтение cookie, resolveHome, проверки состояния, redirect и retry-ветка сохраняются. Provider/context 014 сохраняется в месте, согласованном владельцем; D04 не создаёт второй QueryClient. AccountHeader остаётся серверным slot и получает прежний безопасный профиль.

## Приёмка

320/360/390/768/1280 px, светлая/тёмная тема, 200% текст, длинные подписи, малое окно, keyboard traversal. При resize ввод/результат остаются; число поисковых запросов не растёт. Скрытая панель не получает фокус. Действующие login/logout/retry проходят регрессию.

## Уточнения интерфейса — 2026-10-02

Каркас успешной главной занимает доступную ширину окна с существующими небольшими адаптивными внешними отступами. Ограничение общей ширины 75rem снимается; ширина боковой панели 310 CSS px сохраняется, правая панель получает оставшееся место. На mobile сохраняется одна колонка. Login и серверный retry сохраняют своё оформление.

В HomePage.module.scss заменить ограничение ширины успешного каркаса на доступную ширину. Удалить токен максимальной ширины только если больше нет потребителей. Не менять общие размеры текста, ширину боковой панели или правила данных 014.
