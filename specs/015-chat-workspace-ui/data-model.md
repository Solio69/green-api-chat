# Модель представления D04

Постоянных сущностей и БД нет. Публичный DTO принадлежит 014; здесь описаны только состояния UI.

| Сущность           | Источник               | Допустимые данные                              | Владелец                   |
| ------------------ | ---------------------- | ---------------------------------------------- | -------------------------- |
| Account slot       | Серверная главная/013  | Готовый AccountHeader                          | Сервер, не query-cache D04 |
| Search slot        | Существующая форма 009 | Единственный экземпляр формы                   | RecipientSearchForm        |
| List snapshot      | Публичный хук 014      | Текущие подтверждённые личные чаты и состояния | Query-cache 014            |
| Empty conversation | Локальный UI           | Статичные приглашение/декор                    | Оболочка                   |

Список не копируется в useState. UI различает наличие подтверждённых данных и их длину: пустой массив при загрузке не доказывает пустой успех. Первоначальная ошибка имеет сообщение/повтор без ложного пустого состояния; ошибка обновления сохраняет данные в кэше, но карточка ошибки заменяет строки в UI. В ChatListPanel временно удерживается только код ошибки во время ручного повтора; он не является копией списка, query key или серверной сессии. После завершения повтора представление снова определяется результатом useChats. Состояния и названия полей берутся из фактического контракта 014, а не задаются параллельным DTO.

Строка использует стабильный chatId как React key и подпись из доступных name/username/phone/chatId публичного PersonalChat 014; не создаёт online-статус, avatar, preview, timestamp или local selectedChat. Декоративный инициал — производное оформление той же подписи; фото и новые данные о получателе не добавляются. Resize и тема меняют только CSS; источник списка и форма сохраняют положение в дереве. Конец сессии/изоляция аккаунтов — ответственность 014 и действующей серверной главной.

## Уточнения интерфейса — 2026-10-02

Каркас успешной главной занимает доступную ширину окна с существующими небольшими адаптивными внешними отступами. Ограничение общей ширины 75rem снимается; ширина боковой панели 310 CSS px сохраняется, правая панель получает оставшееся место. На mobile сохраняется одна колонка. Login и серверный retry сохраняют своё оформление.

Новых сущностей, API DTO, query keys и хранилищ нет; уточнение относится к представлению.
