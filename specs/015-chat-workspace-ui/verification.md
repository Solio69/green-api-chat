## Результат

В заголовке «Чаты» нет кнопки обновления. При загрузке, успешных данных и подтверждённой пустоте действие не появляется. Временная ошибка заменяет список карточкой с раздельными заголовком/пояснением и «Обновить»; лимит имеет безопасный отдельный текст. Query-кэш не удаляется. Ручной refetch блокирует кнопку, показывает «Обновляем…» и сохраняет карточку, её положение и размер кнопки. Успех возвращает список/пустоту, повторная ошибка сохраняет карточку. Поиск и выход доступны.

ChatListPanel имеет один useChats и временно удерживает только код ошибки. ChatList — чистое представление данных/loading/empty; собственной копии query-данных, новых DTO или fetch нет. SVG-декор скрыт от вспомогательных технологий. Ошибка — role=alert, ожидание — отдельный role=status. Два текста кнопки занимают одну зарезервированную область; при reduced motion вращение отключено. На узком экране и при 200% тексте подписи переносятся естественно, не по одной букве.

Каркас, профиль, поиск, фон, темы и существующие серверные сценарии сохранены. Список не открывает переписку; отправка/история остаются отдельными задачами. Изменения ограничены ChatListPanel/ChatList, используемыми токенами, четырьмя существующими test/fixture файлами и документацией 015/общего UI. Сервер, Query policy, сессия и зависимости не меняются.

## Покрытие и visual QA

Восемь постоянных E2E списка: начальное ожидание/пустота без кнопки; подписи/инициалы без вымысла; ошибка/один повтор/блокировка; повторная ошибка и пустой успех; лимит; длинные списки; отказ сессии; темы/адаптивность/читаемость. Проверяется отсутствие списка во время ошибки и повтора, отсутствие дополнительного запроса при resize/смене темы. До и во время повтора сравниваются x/y/width/height области и кнопки.

Для карточки проверены 320/1280 px, светлая/тёмная темы, 100%/200% текст, клавиатурный фокус, цели ≥44 CSS px, контраст текста/пояснения/кнопки ≥4.5:1 и reduced motion. Для длинных списков сохраняется матрица 320/360/390/680/681/768/1280 px. Визуально просмотрены свежие `recovery-light-1280-text-100.png`, `recovery-dark-320-text-100.png`, `recovery-dark-320-text-200.png` из fixture-артефактов. Персональные данные и реальные реквизиты не сохранялись.
