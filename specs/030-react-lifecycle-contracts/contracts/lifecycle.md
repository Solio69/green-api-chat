# Контракт проверок провайдеров

| Сценарий | Наблюдаемый результат |
| --- | --- |
| Root StrictMode | Эффект: setup, cleanup, setup; выбранная сессия и контроллер те же; один receive, один lease |
| Несколько потребителей | Общие session/controller; нового читателя нет |
| Rerender | Идентичность объектов и кеш сохраняются |
| Новый key/scope | Старый signal отменён, owner отсутствует, кеш очищен, lease освобождён; новые объекты изолированы |
| Unmount во время receive | После отложенного disposal нет owner, подписок и таймеров; поздняя delivery не меняет кеш и не вызывает ACK |
| Unmount во время lease | Полученный позже lease освобождён один раз, fetch не вызывается |
| Ошибка lease | Доступ ограничен, сети/владения нет; unmount полностью освобождает ресурсы |
| Ошибка одного cleanup | Остальные ресурсы закрываются, кеш очищается |
| Production browser | После смены wrapper и rerender данные видимы без лишних запросов; replay не заявляется |

Spy фабрики использует реальную реализацию и нужен только для наблюдения
заброшенных initializer-объектов. Подмена контроллера/QuerySession запрещена.
Нулевая retry-политика тестового runner сохраняется.
