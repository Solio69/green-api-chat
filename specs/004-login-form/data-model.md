# Локальное состояние формы E03.1

Источник: [spec.md](spec.md). Серверных сущностей, сессии и схемы БД нет.

| Значение         | Тип / начальное значение | Правило                                                                |
| ---------------- | ------------------------ | ---------------------------------------------------------------------- |
| idInstance       | string / пустая строка   | Хранится как введено, включая ведущие нули                             |
| apiTokenInstance | string / пустая строка   | Не нормализуется, не отправляется и не сохраняется                     |
| hasSubmitted     | boolean / false          | Становится true при первой попытке, не сбрасывается при редактировании |
| isTokenVisible   | boolean / false          | Меняется только переключателем; не влияет на значение                  |
| isInteractive    | вычисляемый boolean      | false в серверной разметке и при гидратации, затем true                |
| errors           | вычисляемая карта        | До попытки пуста; затем ошибки для trim().length === 0                 |

Ошибки не дублируются в отдельном изменяемом состоянии. hasSubmitted сохраняется
до размонтирования формы: исправление убирает ошибку, повторное очищение возвращает.

## Переходы

| Событие                            | Результат                                                           |
| ---------------------------------- | ------------------------------------------------------------------- |
| Первое открытие                    | Поля пусты, токен скрыт, ошибок нет; до гидратации ввод отключён    |
| Гидратация                         | Поля, переключатель и кнопка становятся доступны                    |
| Ввод до попытки                    | Меняется только выбранная строка                                    |
| Неполная попытка                   | hasSubmitted=true; ошибки вычислены; фокус на первом пустом поле    |
| Полная попытка                     | hasSubmitted=true; ошибок нет; значения и URL сохранены             |
| Ввод после попытки                 | Меняется строка и производные ошибки; фокус остаётся у пользователя |
| Показ/скрытие                      | Меняется видимость; значения, hasSubmitted и ошибки сохраняются     |
| Перезагрузка                       | Приложение заново создаёт начальное состояние                       |
| Отключённый или заблокированный JS | Поля и кнопки неактивны; реквизиты не отправляются                  |

Полная попытка не создаёт результата «авторизован», сессии, запроса или перехода.
Автозаполнение браузера находится вне прикладного хранилища.
Логирование и сериализация черновика в URL, cookie, Web Storage или IndexedDB
не входят в модель и запрещены контрактом текущей задачи.
