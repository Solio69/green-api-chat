# Проверка D05

**Сейчас**: оформление поиска, formatter и уточнения T009 реализованы и автоматически проверены. Авторизация сохраняется; «Написать» остаётся пустым обработчиком D06.

1. Пользователь входит своими реквизитами самостоятельно. Проверить телефон/username, кнопку/Enter, пустой submit и исправление, очистку старого результата при редактировании/смене режима, ожидание и ошибки.
2. Для username видна подсказка «Можно вводить с @ или без него»; при переключении высота формы не меняется. Вспомогательные технологии получают только активную подсказку; переключение не отправляет POST.
3. Проверить keyboard focus, обе темы, resize с вводом, 320/390/1280 px, текст 200% и длинную подпись. «Написать» не вызывает submit/запроса/навигации/ложного ожидания.
4. При остановленном dev выполнить npm run test:integration, npm run test:e2e, npm run lint, npm run lint:styles, npm run typecheck и npm run format:check. E2E включает production build. [Результаты и исходный TDD formatter](verification.md), [общая регрессия](../017-precommit-refactor/verification.md).

Автоматические тесты используют фиктивные данные. Реальный аккаунт, iPhone/VoiceOver, browser zoom и пользовательское ревью отмечаются по факту; Chromium и font-size:200% их не заменяют. Не присылать агенту токены или переписку. Открытие чата D06 обсуждается отдельно.
