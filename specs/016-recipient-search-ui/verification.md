# Проверка D05

**Дата**: 2026-10-02. **Статус**: реализация, уточнения T009 и сверка оформления с макетом проверены автоматически; полная ручная приёмка NotRun.

## Результат

Сегментированные режимы, поле и компактная кнопка используют нейтральную поверхность, синий акцент выбранного режима, тонкую рамку и мягкую подсветку фокуса; ошибка получает красную рамку/подсветку. Локальные CSS-переменные размеров SubmitButton имеют прежние fallback-значения, login сохраняет своё оформление. Темы, адаптивность, мобильные цели 44 CSS px и текст ввода 16 px сохранены.

Подсказки username/телефона и подписи рассчитывают естественную высоту через CSS Grid; активна только соответствующая подсказка. Смена режима сохраняет высоту пустой формы. Ввод, запрос и валидация остаются у RecipientSearchForm. Успех, отрицательный результат и сбой различимы; «Написать» сохраняет пустой handler D06 и не создаёт чат/запрос. Индикатор и status находятся вне disabled fieldset.
