## Dependencies & Execution Order

T001 → T002 → T003 → T004 → T005 → T006 → T007 → T008 → T009 → T010 → T011 → T012 → T013 → T014 → T015 → T016 → T017. T005 использует контракт T004; T006 проверяет сохранение через внедрённую зависимость, а T008 подключает реальную cookie и HTTP-обработчик. T011 следует после готовности `/api/auth/login` и `/`.

Для каждой пары новая логика проходит сохранённый исполняемый тест → поведенческий Red → минимальную реализацию и Green → Refactor. Отсутствующий модуль, пакет, сервер или секрет не заменяют Red. Тесты не используют настоящий GREEN-API и реальные реквизиты. Маршрутные E2E проверяют поведение браузера, интеграционные — серверные правила с фиктивными ответами. Ручная проверка настоящим инстансом остаётся отдельной.
