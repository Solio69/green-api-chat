# Data Model: E03.2 — вход и сессия

## Реквизиты формы

| Поле | Тип | Правило | Дальнейшее использование |
| --- | --- | --- | --- |
| `idInstance` | строка | Обязательна; пробельное значение пусто; ведущие нули сохраняются | Кодируется как часть фиксированного пути GREEN-API |
| `apiTokenInstance` | строка | Обязательна; не обрезается и не нормализуется; значение скрыто в поле | Кодируется как часть фиксированного пути GREEN-API |

Сервер принимает только JSON-объект с этими строками, отклоняет тело более 8 КБ и не отражает значения в ошибках. Непредусмотренные поля не нужны. Телефон получателя и `apiUrl` не являются полями входа.

## Ответ GREEN-API

Документированное тело `GetStateInstance`: `{"stateInstance":"authorized"}`.
Известные состояния: `authorized`, `notAuthorized`, `blocked`, `suspended`, `starting`, `pendingPassword`. Сервер принимает к обработке только JSON-объект со строковым `stateInstance`. Неизвестное значение не выдаёт успешный вход.

| Класс результата | Примеры | Вход | Действующая сессия на `/` |
| --- | --- | --- | --- |
| Доступ разрешён | `authorized` | Создать сессию | Показать JSON |
| Доступ утрачен | `notAuthorized`, `pendingPassword`, `blocked`, `suspended`, 401/403 | Ошибка формы | Прекратить сессию и перенаправить |
| Временная или неопределённая проблема | `starting`, оба документированных 400 с `starting`, повторный 429, таймаут 10 секунд, сбой сети, 5xx, некорректный ответ | Ошибка с повтором; на форме для повторного 429 — `rate_limited` | Сохранить сессию, предложить повтор |
| Состояние требует кабинета | Подтверждённый `notAuthorized` или известный 400 об истёкшем инстансе | Ошибка с кабинетом | Прекратить сессию при подтверждении потери авторизации |

## Сессия браузера

| Поле | Тип | Назначение |
| --- | --- | --- |
| `idInstance` | строка | Повторная серверная проверка |
| `apiTokenInstance` | строка | Повторная серверная проверка |
| `expiresAt` | timestamp в миллисекундах | Абсолютный срок 24 часа от успешного входа |

Все поля находятся внутри зашифрованной и подписанной cookie. Пустая, изменённая, просроченная или структурно неверная сессия не даёт доступ. Чтение не продлевает срок. Cookie не хранится в БД и не доступна клиентскому JavaScript; браузер отправляет её серверу на запросы приложения.

## Данные ответа нашего API

Успех `POST /api/auth/login` сообщает только, что вход разрешён. Неуспех содержит безопасный код ошибки, а при необходимости известное состояние инстанса и указание поля; реальные реквизиты и полный upstream-ответ не возвращаются. Тексты русских ошибок находятся в UI-константах формы. Контракт задаёт [login-api.md](contracts/login-api.md), переходы `/` — [protected-home.md](contracts/protected-home.md).
