# Contract: защищённая главная /

## Вход и прямой переход

| Состояние                                                                                                                | Поведение                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Cookie отсутствует, истекла, подменена или содержит неверную структуру                                                   | Серверный редирект на `/login`; данные инстанса не отображаются                                                                                        |
| Сессия действительна, актуальный `GetAccountSettings` вернул `authorized`                                                | HTTP 200; безопасный профиль 013 и каркас 015, без сырого ответа провайдера                                                                            |
| Сессия действительна, подтверждена потеря авторизации/доступа                                                            | Cookie удаляется в узком серверном обработчике; затем редирект на `/login` с безопасным кодом причины                                                  |
| Сессия действительна, `starting`, неоднозначный 400 `instance is starting or not authorized`, таймаут или временный сбой | Cookie сохраняется; простой текст об ошибке и ссылка повторить проверку и доступный выход по 008                                                       |
| Сессия действительна, GREEN-API вернул 429                                                                               | Через 1,1 секунды запрос повторяется один раз в общем лимите 10 секунд; при повторном 429 cookie сохраняется и предлагается повторить проверку вручную |
| Сессия действительна, ответ некорректен или состояние неизвестно                                                         | Доступ не подтверждается; cookie сохраняется, отображается возможность повторить проверку                                                              |

Открытие и обновление `/` выполняют новый запрос к `GetAccountSettings`. Автоматический повтор выполняется только для HTTP 429 и не создаёт новую сессию. Чтение сессии не продлевает 24-часовой срок. Защита выполняется на сервере до вывода защищённого содержимого; не зависит от клиентского эффекта или proxy.

## Внутреннее завершение при потере доступа

Серверная страница не может удалить cookie во время рендера. Фиксированный внутренний обработчик прекращает сессию и направляет на `/login`. Он не принимает произвольный URL для редиректа и не выводит реквизиты. Пользовательский выход описан в 008; профиль и состояния актуального метода — в [контракте 013](../../013-account-profile/contracts/account-settings.md).

## Проверки

- Запрос без cookie и с повреждённой cookie не раскрывает данные инстанса.
- Повторное открытие с действующей cookie заново проверяет `GetAccountSettings`.
- Подтверждённая потеря доступа удаляет cookie; временный сбой и `starting` не удаляют.
- Содержимое HTML не включает `idInstance`, `apiTokenInstance` или URL запроса к провайдеру.
