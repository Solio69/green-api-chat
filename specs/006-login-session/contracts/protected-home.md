# Contract: защищённая главная /

## Вход и прямой переход

| Состояние | Поведение |
| --- | --- |
| Cookie отсутствует, истекла, подменена или содержит неверную структуру | Серверный редирект на `/login`; данные инстанса не отображаются |
| Сессия действительна, актуальный `GetStateInstance` вернул `authorized` | HTTP 200; в `<pre>` показан только документированный JSON `{"stateInstance":"authorized"}` |
| Сессия действительна, подтверждена потеря авторизации/доступа | Cookie удаляется в узком серверном обработчике; затем редирект на `/login` с безопасным кодом причины |
| Сессия действительна, `starting`, неоднозначный 400 `instance is starting or not authorized`, таймаут или временный сбой | Cookie сохраняется; простой текст об ошибке и ссылка повторить проверку без дизайна чата |
| Сессия действительна, GREEN-API вернул 429 | Через 1,1 секунды запрос повторяется один раз в общем лимите 10 секунд; при повторном 429 cookie сохраняется и предлагается повторить проверку вручную |
| Сессия действительна, ответ некорректен или состояние неизвестно | Доступ не подтверждается; cookie сохраняется, отображается возможность повторить проверку |

Открытие и обновление `/` выполняют новый запрос к `GetStateInstance`. Автоматический повтор выполняется только для HTTP 429 и не создаёт новую сессию. Чтение сессии не продлевает 24-часовой срок. Защита выполняется на сервере до вывода JSON; не зависит от клиентского эффекта или proxy.

## Внутреннее завершение при потере доступа

Серверная страница не может удалить cookie во время рендера. Фиксированный внутренний обработчик прекращает сессию и направляет на `/login`. Он не принимает произвольный URL для редиректа и не выводит реквизиты. Пользовательский элемент «Выйти» в этот шаг не входит.

## Проверки

- Запрос без cookie и с повреждённой cookie не раскрывает JSON инстанса.
- Повторное открытие с действующей cookie заново проверяет `GetStateInstance`.
- Подтверждённая потеря доступа удаляет cookie; временный сбой и `starting` не удаляют.
- Содержимое HTML не включает `idInstance`, `apiTokenInstance` или URL запроса к провайдеру.
