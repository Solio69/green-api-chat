# Проверка счётчиков

Установки и настройки GREEN-API не требуются. Приложение запускается существующим npm run dev.

1. Открыть А, получить сообщение Б: у Б синий счётчик.
2. Открыть Б: счётчик исчезает.
3. Перейти в другую вкладку браузера, получить сообщение выбранного чата, вернуться: его отметка очищается; отметки других чатов остаются.
4. На телефоне открыть А, получить Б: у «Чаты» сумма; вернуться в список и открыть Б.
5. Перезагрузка начинает новый локальный сеанс отметок. Полное количество непрочитанных Telegram не обещается.

Автоматическая проверка без реального инстанса: npm run test:integration; npm run test:query; npm run test:e2e. Синтетический браузерный сценарий tests/query/unread-indicators.spec.ts использует реальные UI-компоненты и существующую fake Receive/SSE/ACK цепочку. Состояние hidden синтетически управляется через Page Visibility event; не выдаётся за проверку реального переключения ОС.
