# Research: Счётчики

Факты установлены чтением проекта 2026-10-03: applyNotification проверяет active/scope/owner и применяет incoming до ACK; QuerySession задаёт memory defaults и client.clear на close; Workspace уже имеет paneRef и ResizeObserver для фокуса; overlay добавляет неизвестные чаты.

| Вариант | Польза | Цена/риск | Решение |
| --- | --- | --- | --- |
| Только число на чат | Меньше полей | Повтор после чтения способен снова увеличить число | Не выбран |
| Unread IDs + seen incoming IDs в Query | Дедупликация независимо от очистки, одна reactive память | Память растёт с текущим сеансом, как message cache | Выбран и согласован |
| Telegram/server unread storage | Межсеансовое восстановление | Новый источник данных/БД и расширение объёма | Вне задачи |
| Visibility и реальная видимость paneRef | Учитывает фон и мобильную скрытую панель | Один browser hook с cleanup | Выбран |

Никаких новых внешних API/версий/пакетов; исследование опирается на установленный код. Открытая видимая переписка считается прочитанной независимо от scroll position — согласованный простой сценарий, не новая система read receipts.
