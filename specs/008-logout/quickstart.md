# Проверка E03.3 — явный выход

## Автоматические проверки после реализации

Из корня проекта при остановленном dev-сервере:

```powershell
npm run test:integration
npm run test:e2e
npm run typecheck
npm run lint
npm run format:check
```

Проверки выполняются одним итоговым набором после реализации и рефакторинга. До реализации новый серверный тест должен один раз подтвердить поведенческий Red. E2E сам запускает production-сборку; dev-сервер в этой же папке на время прогона останавливают. Новые пакеты, миграции и изменения БД не требуются.

## Ручная приёмка пользователем

1. Запустить приложение через ▶ `dev` в панели NPM Scripts VS Code и войти со своими реквизитами. Токен агенту не передавать.
2. На `/` проверить кнопку «Выйти» под JSON. Нажать её и убедиться, что открывается обычная форма `/login` без сообщения о выходе.
3. Открыть `/` напрямую или обновить адрес: должна открыться форма входа без JSON-ответа.
4. Войти снова. Если GREEN-API временно недоступен и `/` показывает ошибку проверки, кнопка выхода всё равно должна быть доступна.

Сохранение истории сообщений, выход на других устройствах и глобальный отзыв cookie не относятся к этому шагу.
