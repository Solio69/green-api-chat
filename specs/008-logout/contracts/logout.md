# Контракт явного выхода

## `POST /api/auth/logout`

Назначение: завершить сессию текущего браузера после явного нажатия «Выйти». Маршрут не принимает реквизиты в URL или теле запроса и не вызывает GREEN-API.

| Условие                            | HTTP          | Заголовки и результат                                                                        |
| ---------------------------------- | ------------- | -------------------------------------------------------------------------------------------- |
| Cookie присутствует                | 303 See Other | `Location: /login`, `Set-Cookie` удаляет cookie сессии с пути `/`, `Cache-Control: no-store` |
| Cookie отсутствует или уже истекла | 303 See Other | Те же безопасный переход и удаление cookie; повтор не создаёт ошибку                         |

После гидратации fetch следует 303 методом GET без загрузки документа; клиент выполняет переход Next.js на `/login` и обновление данных маршрутизатора. Без JavaScript HTML-форма следует 303 нативно. Показывается обычная форма `/login` без дополнительного сообщения или параметра адреса. Идентификатор и токен не включаются в `Location`, тело ответа или журнал.

`GET /api/auth/logout` не является операцией выхода: метод не реализуется; сервер возвращает отказ для неподдерживаемого метода и не меняет cookie. Внутренний `GET /api/auth/end-session` для подтверждённой потери доступа остаётся отдельным контрактом.

Если запрос не дошёл до сервера или ответ не получен, завершение сессии не подтверждено; ошибка отображается рядом с кнопкой, пользователь может повторить действие. Кнопка и повторная отправка блокируются на время запроса. После успешного ответа новое открытие `/` без повторного входа перенаправляет на `/login`.
