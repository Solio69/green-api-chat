Хук отслеживает фокус React capture handlers, хранит refs и отдельно подписывает

навигации сохраняет зависимости target/accessId/mobilePanel. Effect Events
не вызываются из React focus handlers. Нет прямых обращений к window/document
или глобальных listeners. Blur при CSS-скрытии сохраняет последний внутренний
элемент до callback наблюдателя; явный переход наружу освобождает фокус.
Внешнее действие не теряет фокус при скрытии sidebar или pane, проверено E2E.
