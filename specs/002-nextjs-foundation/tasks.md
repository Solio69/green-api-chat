## Dependencies & Execution Order

Строго T001 → T002 → T003 → T004 → T005 → T006 → T007 → T008 →
T009 → T010 → T011 → T012 → T013.

T001 начинается после отдельного разрешения на код. В T008 требуется
действие пользователя; автоматическая установка агентом недопустима.
Отсутствующая браузерная проверка передаётся пользователю со статусом NotRun/Blocked;
фактическая приёмка завершается только после её результата.

Поведение готовой основы проверено реальными HTTP-запросами и браузером;
постоянного набора автоматических тестов приложения пока нет. Извлечение
констант не меняет контракт: успешные проверки до правки → рефакторинг →
повторные проверки. Искусственный Red не требуется. Новые изменения поведения
требуют TDD по действующим правилам. Отрицательные примеры инструментов
не входят в репозиторий.
