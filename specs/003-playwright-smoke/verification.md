## Ограничения и дальнейшее развитие

Проверены Windows и Chromium; остальные ОС/браузеры, CI и Vercel не входят в объём.
Тесты не проверяют реальную интеграцию GREEN-API и будущую логику чата.

В выводе Node при запуске из окружения агента есть предупреждение о совместном
NO_COLOR/FORCE_COLOR. Оно относится к окраске терминала; build, тесты и отдельный
ESLint завершились успешно. Среда пользователя и системные переменные не менялись.

Следующее полезное улучшение — запуск этого же набора в CI после согласования
соответствующей задачи: это проверит изменения независимо от локального запуска.
Дополнительные unit/component-инструменты оцениваются по новой логике, сейчас
необходимость в них не подтверждена.

## Действия пользователя

В NPM Scripts:
1. test:e2e — повторить сборку и три проверки при остановленном dev.
2. test:report — посмотреть последний HTML-отчёт.
3. dev — вернуться к разработке после завершения тестов.

Для проверки типов/линтера/формата доступны соответствующие кнопки.
Установка уже выполнена; повторять её для обычного прогона не требуется.
Пользователь просматривает изменения в Source Control и создаёт коммит сам.

Предлагаемое название коммита:
chore: add Playwright smoke tests for the app foundation
