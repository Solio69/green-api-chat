## Ограничения и развитие

Проверены Windows и Chromium. Другие ОС/браузеры, CI, Vercel и GREEN-API
не входят в объём. npm ci на новой копии не выполнялся. Особенности npm ls
и предупреждение Node о цветах терминала отражены в verification;
обязательным проверкам они не помешали.

Полезное следующее улучшение — согласовать запуск этого набора в CI, чтобы
проверять изменения независимо от локальных действий разработчика.
Дополнительные тестовые инструменты выбираются по конкретной новой логике.
