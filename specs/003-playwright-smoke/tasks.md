## Dependencies & Execution Order

T001 → T002 → T003 → T004 → T005 → T006 → T007 → T008 → T009 → T010 →
T011 → T012 → T013.

T003 включает действия пользователя; без установки runtime-проверки не выполняются.
При занятости dev пользователь останавливает свой процесс; агент его не завершает.
Failed/Blocked не превращаются в выполненные задачи, требующие этого результата.

Задача добавляет регрессионные тесты существующего поведения и конфигурацию.
Продуктовая логика и серверный контракт не меняются; T007 подтверждает исходный
успех, T008 проверяет чувствительность тестов. Это не ретроспективный TDD.
Изменение поведения приложения обсуждается отдельно и требует Red → Green →
Refactor с сохранёнными тестами; обходить проверку изменением src/ нельзя.

## Operator-only actions

Пользователь устанавливает npm-пакеты и Chromium, останавливает свои процессы
и создаёт коммит. Агент не скачивает пакеты/браузеры, не меняет Git и данные БД.
Точные команды установки и кнопки запуска находятся в [quickstart.md](quickstart.md).
