# Contract 055 — критерии итогового состояния

1. Локальные команды из `package.json` запускаются на одном дереве после последней содержательной правки. Typecheck подтверждает app, Vitest, Query fixture; lint/styles/format проходят; Vitest, Query Chromium и production E2E дают точные счётчики и статус. Browser suites не конкурируют за сборки/порты. Если E2E production build недоступен, отдельный `npm run build` получает собственный статус.
2. `coverage-reconciliation.md` охватывает G01–G08 из 028; каждый указанный B028 ID существует в карте 051, 052 или 053, текущий test path существует, название/контракт сверены с тестом. Исторические GAP-01–04 и DEFECT-01 сопоставлены с результатами 030/031/033/034/053 либо зарегистрированы открытыми.
3. README и действующие документы называют `src/features`, `src/shared`, `src/server`, текущие scripts и границы Vitest/RTL/Playwright; пути `src/lib`/`src/components` допускаются только как историческое описание, не как инструкция импортировать. HTTP polling — текущий механизм. Локальные Markdown-ссылки и задокументированные npm-команды разрешаются.
4. После exact-path staged review и push `refactor` CI run на final full SHA завершается `success` с `quality=success`, `browser=success` и обоими artifacts. До этого `verification.md` и roadmap не объявляют всю 028–055 программу завершённой. Отсутствие реального провайдера и deploy записано как ограничение, не как провал фиктивной регрессии.
