## Dependencies & Execution Order

Для документов: T001 → T002 → T003 → T004 → T005. Последовательные прогоны T006 → T007 опираются на зафиксированный контекст T001 и доступное окружение; изучение их результатов не зависит от готовности описания матрицы. T008 требует результатов T003–T007; затем T009 → T010. Полный предварительный анализ обязателен до T001. При исправлении содержательной ошибки документов повторяется затронутая сверка и анализ; неизменный продуктовый набор повторно не запускается без причины.

T010 не помечается заранее выполненной галочкой: её результат подтверждают существующий commit, его проверенный список файлов и итоговый статус Git в ответе пользователю. Отчёт подготовки фиксируется до commit; рекурсивный служебный commit ради записи собственного хеша не нужен.
