# Data Model: данные своего аккаунта

**Spec**: [spec.md](spec.md)
**Статус**: Реализованные внутренние данные; нового хранения нет.

## Вход серверного чтения

`InstanceCredentials` остаётся существующим контрактом: `idInstance` и `apiTokenInstance`. Их читает сервер из текущей сессии. Они не входят в пропсы шапки и не используются как данные получателя.

`getAccountSettings` получает именованный объект с `credentials`; тестовые зависимости `fetcher` и `waitForRetry` необязательны. Новые функции с несколькими аргументами также используют именованные объекты.

## Необработанный ответ поставщика

До проверки ответ имеет тип `unknown`. Корректный объект со знакомым `stateInstance` проверяется существующим классификатором. При `authorized` поля отображения обрабатываются отдельно:

| Поле                                                         | Использование                                                                                |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| `username`                                                   | Непустая строка после trim; приоритетная подпись                                             |
| `phone`                                                      | Непустая строка после trim, только если username отсутствует                                 |
| `avatar`                                                     | Абсолютный допустимый HTTPS URL, иначе пустое значение                                       |
| `chatId`                                                     | Идентификатор самого аккаунта; не передаётся в шапку и не используется для поиска получателя |
| `historySyncProgress`, `suspendedUntil`, дополнительные поля | Не передаются в UI и не создают новых возможностей                                           |

Неверный тип, отсутствие, пробельное значение или обнаруженные реквизиты текущего инстанса делают соответствующее поле отображения отсутствующим. Валидный `authorized` при этом сохраняется.

## AccountProfile

Путь типа: `src/lib/account/types.ts`.

| Поле        | Тип    | Смысл                                                                  |
| ----------- | ------ | ---------------------------------------------------------------------- |
| `label`     | string | Проверенный username либо телефон; `EMPTY_STRING` при отсутствии обоих |
| `avatarUrl` | string | Проверенный источник фото либо `EMPTY_STRING`                          |

Это DTO только для отображения. Он не содержит `idInstance`, `apiTokenInstance`, cookie, собственный `chatId` или копию исходного ответа.

`AccountHeader` получает DTO и существующий текст выхода. Если `label` пуст, компонент показывает «Telegram-аккаунт». Полный идентификатор отображается текстом с переносом, без HTML-интерпретации.

## AccountSettingsResult

- Успех: `kind: authorized`, `body: { stateInstance: authorized, profile: AccountProfile }`.
- Подтверждённый отказ: существующие категории `invalid_token`, `invalid_instance`, `instance_expired`, `needs_authorization`, `instance_restricted`.
- Временная ошибка: существующие `retry_later`, `rate_limited`, `service_unavailable`, `invalid_upstream_response`.

Ошибочные варианты переиспользуют соответствующую часть `StateResult`. Сырое тело ошибки и исключение с URL поставщика не возвращаются в UI.

## Решение защищённой страницы

| Условие                         | HomeResult                             | Последствие                                  |
| ------------------------------- | -------------------------------------- | -------------------------------------------- |
| Нет действующих реквизитов      | `login`                                | Переход на `/login`, нет запроса API         |
| Подтверждён `authorized`        | `authorized` с подготовленным профилем | Шапка и поиск                                |
| Подтверждённый отказ доступа    | `end_session`                          | Действующий обработчик завершения сессии     |
| Временная ошибка или исключение | `retry`                                | Сессия сохранена, повторная проверка и выход |

Вызов `resolveHome` получает именованный объект `{ credentials, getAccountSettings }`. Только выбранный загрузчик аккаунта обращается к GREEN-API; отдельного загрузчика состояния на главной нет.

## Локальное состояние аватара

`AccountAvatar` получает только `avatarUrl`. Локально хранит URL, загрузка которого завершилась ошибкой. Для пустого источника и текущего ошибочного URL показывает иконку. Изменение URL позволяет загрузить новое изображение, не наследуя ошибку предыдущего.

При обновлении страницы компонент получает новый профиль с сервера. Cookie остаётся прежнего формата; профиль и результат проверки в неё не записываются. БД, localStorage, sessionStorage и новый глобальный store не применяются.
