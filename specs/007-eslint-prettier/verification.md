## Границы результата и дальнейшие действия

Stylelint, проверка структуры, общий check, полный перенос CODE_STYLE,
CODING_RULES и skill относятся к следующим отдельно обсуждаемым задачам.
Смысловые правила параметров, условий и JSX нельзя считать автоматически покрытыми.

Пользователь просматривает diff; при собственных правках запускает из NPM Scripts
lint:fix → format, затем lint, format:check и typecheck. Поведенческие изменения
требуют соответствующих тестов по принятому TDD-флоу.

Название коммита для изменений текущей задачи:
chore: enforce ESLint and Prettier code style.
