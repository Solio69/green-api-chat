# Research: Ручное переключение темы

**Дата**: 2026-10-04

## Фактическое состояние

`src/app/globals.scss` применяет `theme.system-theme` к `:root`. В `src/styles/_theme.scss` палитра меняется через `prefers-color-scheme: dark`. Тема не хранится. `AccountHeader` содержит аватар, подпись подключения и `LogoutButton`; мобильный и широкий интерфейсы показывают этот блок в боковой панели. `tests/e2e/account-profile.spec.ts` уже проверяет системные палитры на двух viewport.

## Решения

1. Сохранение только в `localStorage`, без серверного cookie: выбор не чувствителен, а серверу он не нужен. При недоступном storage изменение действует в текущей странице.
2. Отсутствие валидного значения сохраняет системный режим, а явное `light`/`dark` блокирует дальнейшее влияние системной темы до следующего ручного выбора.
3. Ранний inline-скрипт из доверенной константы ставит атрибут `<html>` до показа страницы. `suppressHydrationWarning` нужен только на корневом элементе, чей атрибут может измениться до гидратации.
4. Два SVG внутри кнопки переключаются CSS-переменными палитры, чтобы пиктограмма без состояния React соответствовала теме уже на первом кадре.
5. Кнопка — клиентский компонент в серверной главной странице, вне шапки аккаунта. Верхняя полоса резервирует место над рамкой чата; существующая иконка выхода и её поведение не меняются.

Новых пакетов, внешних API и сетевых запросов эта задача не требует. URL демо дан пользователем; веб-инструмент не смог открыть его, поэтому доступность не подтверждена.
