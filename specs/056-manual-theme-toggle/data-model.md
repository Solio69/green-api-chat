# Data model: Локальная тема

**Значение**: `light` или `dark`, либо отсутствующее/невалидное значение.

**Хранение**: один локальный ключ браузера на origin; никакой серверной сущности.

**DOM-проекция**: `document.documentElement.dataset.theme` содержит явное значение; отсутствие атрибута означает автоматический режим.

| Текущее состояние | Событие | Новое состояние |
| --- | --- | --- |
| Авто + система light | Нажатие | `dark`, сохранено локально |
| Авто + система dark | Нажатие | `light`, сохранено локально |
| Ручное light | Нажатие | Ручное `dark`, сохранено локально |
| Ручное dark | Нажатие | Ручное `light`, сохранено локально |
| Любое | Загрузка с валидным значением | Соответствующая ручная тема |
| Любое | Загрузка без валидного значения | Авто; CSS следует системе |

Ошибка чтения эквивалентна отсутствию значения. Ошибка записи не отменяет DOM-переключение текущей страницы. В интерфейсе нет третьей команды возврата к автоматическому режиму.
