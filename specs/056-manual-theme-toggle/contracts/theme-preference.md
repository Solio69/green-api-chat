# UI contract: theme preference

- Кнопка у самого правого верхнего края окна, выше рамки чата и вне шапки аккаунта, имеет `type="button"`, доступное имя и видимый `:focus-visible`; её область не меньше 44 × 44 CSS px.
- В автоматическом состоянии корень не имеет `data-theme`. При `prefers-color-scheme: light` видны светлая палитра и луна; при `dark` — тёмная палитра и солнце.
- При нажатии корень получает `data-theme="dark"` или `data-theme="light"`, CSS применяет соответствующие переменные ко всему приложению без перезагрузки.
- В `localStorage` хранится только `light` или `dark`. Ранний скрипт применяет исключительно эти два значения; другие значения не интерпретирует.
- У кнопки нет меню, видимой подписи и серверных запросов. Ошибки storage не препятствуют текущему переключению.
